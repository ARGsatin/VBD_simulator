5、关于测试的建议：可以就单做一个四面体，去做数值测试，相当于就4个颜色，每个顶点1个，ground truth你可以直接手算出来，你的代码算出来的数值要match。先不要整成这么耦合的系统，先调弹性部分，就没有重力，你自己给一些顶点加约束或者加外力，你去测一下数值对不对。比如你就一个四面体，固定3个顶点，外力拉另外一个了，再往后就是你把一个简单的正方体划分成几个四面体，然后固定4个顶点拉4个顶点。

​	数值上比较好的测试方法就是你的lagrangian在求解后肯定是减少的，就是你数学上是在最小化一个函数，你要保证求解前后函数的值是减小的。还有验证你的hessian以及gradient算的对不对，就是你直接用有限差分法，可以做对照。如果有解析是最好，没有解析你就用有限差分。弹性能可以这么验证，整个lagrangian也可以这么验证



6、没做碰撞监测的原因：是把模型分为上下平台，然后上平台向上位移驱动，拉扯这个模型，然后下平台到达临界力后解除位移限制，同时再额外施加一个随位移变小的真空负压力，最终观察稳定状态的位移。然后一开始划分网格先把模型分层，仿照逐层打印，单层是像上一段话描述那样运动，然后再保留上一层变形，解锁下一层顶点，从下平台重新开始剥离运动，最后输出成动画序列。
